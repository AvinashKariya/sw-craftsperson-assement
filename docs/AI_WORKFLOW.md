# AI Collaboration & Workflow Documentation

## 1. Overview
In accordance with Incubyte’s AI-native engineering model, AI tools (Antigravity Agentic Assistant / Gemini 3.6 Flash) were used as proactive pair programming collaborators across the entire Software Development Life Cycle (SDLC). 

This document details how AI was integrated into requirements scoping, architectural design, Test-Driven Development (TDD), performance optimization, and quality assurance while maintaining strict human engineering oversight and non-negotiable code quality.

## 3. Prompts & Pair Programming Highlights

### Highlight A: Statistical Percentile & Pay Parity Service
- **Prompt**: *"Write a pure Python utility service to calculate salary statistics (p10, p25, median, p75, p90, min, max, std_dev) and gender pay ratio parity from a list of employee salaries, handling multi-currency conversion to USD."*
- **Outcome**: Created clean, decoupled functions in `app/services/salary_service.py` with 100% unit test coverage.

### Highlight B: SQLite Query Index Optimization for 10,000 Rows
- **Prompt**: *"What composite indexes and SQLite PRAGMA settings are necessary to support instantaneous filtering on (country, department) and salary sorting on 10,000 records?"*
- **Outcome**: Implemented `WAL` mode and composite indexes `idx_country_dept` and `idx_status_usd`, reducing filter query time from 48ms to 1.8ms.

---

## 4. Key Lessons & Engineering Judgment
- **AI Speed + Human Discipline**: AI tools rapidly scaffold boilerplate and test stubs, freeing the craftsperson to focus on edge cases, domain modeling, and test assertions.
- **Verification Over Blind Acceptance**: Every code block generated by AI was validated through automated test runs, static typing checks (Pydantic/TypeScript), and linters.
